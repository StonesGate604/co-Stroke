# co-Stroke v4.1: vector + partial-canvas encoding

V4.1 adds a raster view of the current drawing without removing the precise
stroke representation introduced in v4.0. The model is still trained to
contribute one complete stroke per interaction turn.

## Training example construction

For a Quick, Draw! sketch with strokes `S = [s0, ... sn]`:

1. choose one target stroke;
2. choose an ordered prefix or arbitrary subset of the other strokes;
3. resample each visible vector stroke to 16 arc-length points;
4. render **only those visible strokes** to a 64 x 64 partial canvas;
5. predict the hidden target's absolute start, relative shape, and stop state.

The completed sketch is never rendered into the input. This is important: if
the hidden target were present in the raster, training would leak the answer.

## Raster channels

The partial canvas has three channels:

| Channel | Contents | Purpose |
| --- | --- | --- |
| 0 | all visible strokes | overall composition and occupied regions |
| 1 | AI-authored visible strokes | separate previous model output from user input |
| 2 | latest human/non-AI stroke | emphasize the user's most recent contribution |

Quick, Draw! does not contain human/AI collaboration labels. Training therefore
uses the same synthetic author labels as v4.0. Channel 0 is always complete, so
the image branch never depends on the synthetic distinction.

## Architecture

```text
visible vector strokes
    -> per-stroke shape/spatial/author/order embeddings
    -> bidirectional relational Transformer
    -> vector context -------------------------------+
                                                       |
visible strokes -> 3 x 64 x 64 partial canvas           |
    -> strided CNN -> 4 x 4 spatial feature grid         |
    -> raster context ----------------------------------+-> fusion -> GMM heads
                                                                    |-> next start
                                                                    |-> relative shape
                                                                    +-> stop state
```

The CNN retains a coarse 4 x 4 spatial grid before projection instead of using
global average pooling. That lets it distinguish missing content in different
parts of the canvas.

An auxiliary raster-only completion loss is added at weight `0.20`. It has
independent GMM and stop heads, so it cannot pull the pretrained main output
heads away from their v4.0 distribution. Its purpose is to ensure that the
vector branch cannot minimize the main loss while ignoring the new image
encoder. Unit tests also verify that the raster encoder receives non-zero
gradients.

## Warm start

The vector Transformer and mixture heads have the same parameter names and
dimensions as v4.0. A v4.0 checkpoint can initialize those weights while the
CNN and fusion tensors start new:

```powershell
.\.venv\Scripts\python.exe -u scripts\train_stroke_multimodal_v41.py `
  --data data\quickdraw\cat.ndjson `
  --out-dir runs\stroke-multimodal-v41-cat `
  --max-drawings 70000 `
  --epochs 12 `
  --batch-size 128 `
  --init-checkpoint runs\stroke-relational-v4-cat\checkpoint.pt `
  --device cuda
```

The checkpoint type is `stroke-multimodal-v4.1`. The existing HTTP service
auto-detects it and constructs the same three raster channels from the current
browser timeline before sampling candidates.

When warm-starting, pretrained v4 parameters use one quarter of the learning
rate assigned to the new raster, fusion, and auxiliary parameters. The best
checkpoint is selected by the fused main validation loss, not by the combined
main-plus-auxiliary objective.

## Cat checkpoint

The first full checkpoint used 69,872 recognized Quick, Draw! cat sketches and
12 epochs. The best epoch was 12:

| Metric | Value |
| --- | ---: |
| parameters | 6,837,054 |
| raster size | 64 x 64 |
| v4.0.1 validation main loss | approximately -3.6114 |
| v4.1 validation main loss | -3.7397 |
| v4.1 raster-only auxiliary loss | -3.1918 |

The validation likelihood improvement establishes that the raster context adds
predictive information. Visual interaction tests are still required to measure
duplicate-part reduction and perceived drawing quality.

## Scope of the improvement

V4.1 gives the model a whole-canvas representation and a way to distinguish
human from generated ink. It does not yet provide explicit labels for cat parts
such as ear, eye, nose, or whisker. Recognizability and part-state objectives can
be added later, after measuring whether the raster branch reduces duplicate
structures and improves missing-stroke placement.
